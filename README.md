# Фреймворк для тестирования JSONPlaceholder API.
Комплексный фреймворк для автоматизированного тестирования REST API JSONPlaceholder (https://jsonplaceholder.typicode.com/). 
Проект реализует надежный набор тестов с использованием Python и pytest для проверки CRUD-операций на эндпоинте /posts.

### Возможности.

- Полное тестирование CRUD-операций (GET, POST, PUT, DELETE).
- Параметризованные тесты для множества сценариев.
- Управление сессиями с переиспользованием запросов.
- Негативные тест-кейсы для проверки обработки ошибок.
- Чистый, поддерживаемый код, соответствующий стандартам PEP8.
- Комплексные проверки статус-кодов, структуры JSON и валидации данных.

### Технологии.
- Python 3.8+
- pytest 8.3.3
- requests 2.32.3
- Дополнительно: pytest-html для отчетов, pytest-xdist для параллельного выполнения

## Структура проекта.
Tivali/
├── tests/
│ ├── init.py
│ ├── conftest.py # Фикстуры и конфигурация.
│ └── test_posts.py # Основной набор тестов для /posts.
├── requirements.txt
├── README.md
└── .gitignore

### Описание файлов.
- **tests/conftest.py**: Содержит класс APIClient для управления сессиями и фикстуры pytest. Обеспечивает переиспользуемую сессию между тестами.
- **tests/test_posts.py**: Основной набор тестов с 16+ тест-кейсами, покрывающими все CRUD-операции, параметризацию и граничные случаи.
- **requirements.txt**: Указывает все зависимости с точными версиями для воспроизводимости.
- **.gitignore**: Исключает кэш-файлы Python, виртуальные окружения и файлы IDE.

## Установка.
### Требования.
- Python 3.8 или выше.
- pip 

### Настройка.
1. Клонируйте репозиторий:
git clone https://github.com/Anton-Sergeev-EA/Tivali.git
cd Tivali
2. Создайте и активируйте виртуальное окружение:
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
3. Установите зависимости:
pip install -r requirements.txt

## Запуск тестов.
Базовое выполнение тестов.
- Запустить все тесты с подробным выводом:
pytest tests/ -v
- Запуск конкретных классов тестов.
pytest tests/test_posts.py::TestPosts -v
- Запуск с различными конфигурациями.
Генерация HTML-отчета:
pytest tests/ --html=report.html --self-contained-html
- Запуск тестов параллельно (используя несколько ядер CPU):
pytest tests/ -n auto
- Запуск только определенных тестов по ключевому слову:
pytest tests/ -k "get_single_post"

## Реализованные тесты:
1. GET-операции.
- Получение всех постов.
- Получение одного поста (параметризованный).
- Получение с параметрами запроса.
- Получение несуществующего поста (негативный).
2. POST-операции.
- Создание нового поста с полными данными.
- Создание поста с различными наборами данных (параметризованный).
- Создание поста с некорректными данными.
3. PUT-операции.
- Обновление существующего поста.
- Частичное обновление (параметризованный).
- Обновление несуществующего поста (негативный).
4. DELETE-операции.
- Удаление существующего поста.
- Удаление несуществующего поста (негативный).
5. Граничные случаи.
- Доступ к несуществующему эндпоинту.
- Неверные HTTP-методы.
- Обработка некорректных данных.

## Непрерывная интеграция.
Проект может быть интегрирован в CI/CD пайплайны. Пример конфигурации для GitHub Actions:
- yaml.
name: API Tests
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - uses: actions/setup-python@v2
        with:
          python-version: '3.10'
      - run: pip install -r requirements.txt
      - run: pytest tests/ -v --html=report.html
      - uses: actions/upload-artifact@v2
        with:
          name: test-report
          path: report.html

# Устранение неполадок.
## Частые проблемы:
- Ошибки соединения: Убедитесь, что у вас есть доступ в интернет и API доступен.
- Ошибки SSL-сертификатов: Обновите установку Python или сертификаты.
- Падение тестов: Проверьте статус API по адресу https://jsonplaceholder.typicode.com.
